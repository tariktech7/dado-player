# 0.6.1 playback and TV navigation — 2026-11-15

## Result

Built Windows portable, Android build 15, iOS build 10 and Samsung 0.6.1. Samsung installed in place on GQ77S94CATXZG (192.168.178.69) and launched successfully after the animation/focus fixes. No uninstall/reset was used.

## Changes

- iOS AVPlayer error -11828: AVFoundation cannot recognize the stream container. Real provider movie/episode extensions are retained. Automatic HLS uses AVPlayer; file/opaque streams use embedded MobileVLCKit 3.7.3. AVPlayer can fall back once with the same URL/resume position. Own Dado controls remain default; Apple controls/forced engines are expert choices.
- VLC surface supports pause, seek/resume, volume, EOF, audio/subtitle IDs and language metadata. No fake cache/FPS statistics. Late callbacks are scoped to the active decoder/item.
- Checksum-pinned SDK download, arm64 dynamic framework embedding, executable rpath, LGPL license/source notice and IPA dyld validation. Embedded framework must be re-signed along with the app by AltStore/Sideloadly.
- Integrated Android playback in automatic mode, existing external apps only by expert opt-in. Easy-mode settings migrate once; expert choices stay intact. Windows keeps integrated libmpv.
- Samsung automatic AVPlay -> one HTML-video fallback. Same URL/position, no fake extension conversion. A browser engine does not add hardware codec support.
- Samsung navigation grid switches layout once; FLIP transform animations replace per-frame grid-width layout. Focus no longer triggers a whole-app resize/render. Reduced motion and rapid reversals are supported.
- Settings groups have independent focus memories. Left crosses to the neighboring settings column before the main rail; Up/Down crosses vertically within its column. Checkboxes no longer trap Left/Right as if they were editable text. Back returns to the current menu navigation, then opens the exit confirmation. Dialog/input/player close priority is preserved.

## Hardware limits

No iPhone is connected here. The new iOS decoder has been compiled/linked/packaged, but the user must install it with their Apple ID and verify the previously failing provider films/episodes on their iPhone. The exact failing provider file was not supplied for inspection. The implementation addresses unsupported containers; invalid URLs, unavailable provider streams, DRM and unsupported codec/hardware combinations cannot be guaranteed by a build test. TV animation mechanism/focus tests passed in Chromium; smoothness and actual provider playback still need confirmation on the television. Samsung USB packaging still awaits Samsung-issued TMG/widget.license; the ZIP remains preparation only. Beta download/update channels remain unchanged until device acceptance.
